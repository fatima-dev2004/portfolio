Mes projets en détail

Plateforme de reporting industriel

SEWS Cabind Maroc · Stage Full Stack · juillet–août 2025

Une plateforme web qui automatise la collecte, l’analyse et la diffusion des indicateurs de production pour les managers sur site.

  • Interface React.js et Tailwind CSS avec tableau de bord dynamique (Recharts, Chart.js), adaptée à tous les écrans.
  • API REST sécurisée avec Spring Boot (architecture Controller-Service-Repository), Spring Security et JWT, avec les rôles Admin, Manager et Employé et des permissions granulaires.
  • Base de données relationnelle MySQL, gérée avec Spring Data JPA et Hibernate.
  • Import de fichiers Excel (Apache POI) tolérant aux colonnes mal saisies.
  • Rapports PDF/Excel avec JasperReports, envoyés automatiquement à l’heure prévue grâce à Spring Scheduler et Spring Mail.
  • Journal d’audit de toutes les actions des utilisateurs.
  • React.js
  • Tailwind CSS
  • Spring Boot
  • JWT
  • Hibernate
  • MySQL
  • JasperReports

Outil de maintenance préventive (GMAO)

Auto Nejma S.A. · Stage Full Stack · août 2025

Un outil de suivi des interventions sur véhicules et équipements : planification, notifications et historique.

  • Backend PHP structuré en sept modules : authentification, tableau de bord, techniciens, planification, interventions, notifications et historique.
  • Interface HTML, CSS et JavaScript simple et ergonomique pour les techniciens et les responsables.
  • Base de données MySQL déployée sous XAMPP et administrée avec phpMyAdmin.
  • Modélisation UML avant le développement : cas d’utilisation, classes et séquences.
  • Alertes automatiques pour les maintenances planifiées ou en retard.
  • Rapports d’activité exportables en PDF et CSV pour faciliter la prise de décision.
  • PHP
  • HTML/CSS/JavaScript
  • MySQL
  • XAMPP
  • phpMyAdmin
  • UML

HydroGym, application web de fitness

Projet personnel · Angular + Spring Boot

Application web de fitness qui accompagne l’entraînement et le suivi de la progression.

  • Programmes d’entraînement personnalisés (Push, Pull, Legs, Full Body), défis quotidiens avec XP et niveaux, et coach virtuel basé sur l’IA.
  • Séances guidées série par série, avec charges modifiables et minuteur de repos.
  • Suivi du poids et journal des charges par exercice.
  • Authentification sécurisée (inscription, connexion, JWT) et API REST Spring Boot.
